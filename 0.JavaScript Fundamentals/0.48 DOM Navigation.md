- DOM Navigation: The process of navigating through the structure of HTML document using JS. Some functions are:
    - .firstElementChild 
        - it gets the first child item of the element referenced
        - e.g: element = document.getElementById("fruits"); element.firstElementChild; // returns apple
    - .lastElementChild // similar to firstElementChild but returns last child element
    - .nextElementSibling
        - all children elements are siblings (in this case the `<li>` or even the `<ul>`)
        - element = document.getElementById("apple"); element.nextElementSibling; // returns orange
    - .previousElementSibling // similar logic for previous sibling
    - .parentElement
        - returns the parent element of the selected element
        - element = document.getElementById("apple"); element.parentElement; // returns the entire `<ul ide=fruit>` HTML Collection
    - .children // return all the children elements
