- EventListeners: Listen for specific events to trigger any action when that event occurs
    - Some of the common events are: keyup, keydown
        - keydown: when you press a key
            - if a key pressed and held (not releasing it), it returns the same object multiple times for that duration
        - keyup: when you release a key
    - the function to trigger code on the event is:
        - addEventListener(event, callback); // the event object is provided by the web browser automatically when something happens containing details about what happened exactly

```
document.addeventEventListener("keydown", event => {
    console.log(event.key); // will display the event details of the specific key that was pressed.
});

document.addeventEventListener("keyup", event => {
    console.log(event.key); // will display the event details of the specific key that was released.
});
```
