- .map(): Accepts a callback and then applies that callback to each element of an array and returns the new array
    - It is very similar to forEach(), however **it returns the new array** is the key difference

```
//Function to square the numbers in an array
const numbers = [1,2,3,4,5];

function square(element){
    return Math.pow(element, 2);
}

const sq_numbers = numbers.map(square)
```
