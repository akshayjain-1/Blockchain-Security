- getter: Special method that makes a property readable
- setter: Special method that makes a property writable

```
class Rectangle{
    
    constructor(height, width){
        this.height = height;
        this.width = width;
    }
}

const rect = new Rectangle(-10000, "pizza");
```
- this sets the height to a negative number and the width to a string. We can use setter to validate and set the value

```
class Rectangle{
    
    constructor(height, width){
        this.height = height;
        this.width = width;
    }

    set height(newHeight){
        if(newHeight > 0){
            this._height = newHeight // _height is a private property
        }
        else{
            console.error("Height must be positive")
        }
    }

    set width(newWidth){
        if(newWidth > 0){
            this._width = newWidth
        }
        else{
            console.error("Width must be positive")
        }
    }
}

const rect = new Rectangle(3, 5); // will error if the height or width is a non positive integer
console.log(rect.height) // will not display the value
console.log(rect.width) // will not display the value
```
- In the previous example the values are not visible in console log. This is because, set() only makes the property writable and not readable. Thats where we need get()

```
class Rectangle{
    
    constructor(height, width){
        this.height = height;
        this.width = width;
    }

    set height(newHeight){
        if(newHeight > 0){
            this._height = newHeight // _height is a private property
        }
        else{
            console.error("Height must be positive")
        }
    }

    set width(newWidth){
        if(newWidth > 0){
            this._width = newWidth
        }
        else{
            console.error("Width must be positive")
        }
    }

    get width(){
        return this._width;
    }

    get height(){
        return this._height;
    }
}

const rect = new Rectangle(3, 5); // will error if the height or width is a non positive integer
console.log(rect.height)
console.log(rect.width)
```

- With getter we can even add additional logic
```
get area(){
    return this._height * this._width;
}

rect.area;
```
