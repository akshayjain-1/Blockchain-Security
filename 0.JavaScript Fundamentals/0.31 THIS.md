- `this`: It is a keyword that references the object where THIS is used
    - `person.name = this.name`
    - So if we have a person object with name property, we can reference `person` by `this` as long as we are withing the context of that `person` object

```
const person = {
    name: "Spongebob",
    age: 20,
    sayHello: function(){console.log(`Hi! I am ${name}`)}
}
person.sayHello();

// When this executes, it only logs `Hi! I am` and does NOT display the name

// Therefore to correctly access the property, it needs to be preceeded with `this`

const person = {
    name: "Spongebob",
    age: 20,
    sayHello: function(){console.log(`Hi! I am ${this.name}`)} //this.name
}
person.sayHello();
```
***`this` keyword does not work with Arrow functions***

```
const person = {
    name: "Spongebob",
    age: 20,
    sayHello: () => {console.log(`Hi! I am ${this.name}`)}
}
person.sayHello();
```
- This will not work, because when using `this` with arrow function, `this` references the `window` object instead of the defined object
