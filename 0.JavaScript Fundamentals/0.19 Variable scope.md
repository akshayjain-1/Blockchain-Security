Variable scope is basically understanding where the variable is recognized and accessible (local vs global)
- Within a given scope all variables should be named uniquely.
- You can reuse the name as long as they are in different scopes

- Functions cannot see inside other functions. All the activities within a function are local to them this making the scope od variables defined within a function as local
    - They are like neighbouring houses

- On the contrary, any variable defined outside of the function is of global scope as it can be accessed by any element within the code

- If we have variable defined in global scope and then a variable of the same name defined locally, the locally defined value takes precedence within a function
