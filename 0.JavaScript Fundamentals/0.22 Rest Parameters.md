- Rest parameters allow a function to work with variable number of arguements by bundling them into an array: also represented using the same as spread operator `...`
    - The spread parameter unpacks an array into separate elements
    - The rest operator pack separte elements into an array

**To avoid any confusion since both are represented using the same symbol. When used as a part of an function parameter - It is a rest parameter (combine multiple args into 1)**
**When the argument provided to the `...` is an array, it works as a spread operator (separates array into separate element)**

```
// Rest operator

function openfridge(...foods){
    console.log(foods);
}

let food1 = "pizza";
let food2 = "burger";
let food3 = "chowmein";
let food4 = "lassi";

openfridge(food1, food2, food3, food4);

// here multiple args were passed which were consolidated into an array. if the argument would instead be an existing array, it would work as a spread operator
```
