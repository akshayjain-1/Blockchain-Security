- .reduce() - Reduce elements of an array to a single value
- The callback function will have 2 parameters, previous element and next element

```
// return total of all prices

const prices = [1, 2, 4, 5, 6, 7, 10];

function sum(accumulator, element){
    return accumulator + element;
}

const total = prices.reduce(sum);

// Functionin of the reduce method
Iteration 1:
previous element = 1, next element = 2
--> returns 3

** The returned value becomes the "previous element" for the next iteration

Iteration 2:
previous element = 3, next element = 4
--> returns 7

Iteration 3:
previous element = 7, next element = 5
return 12
...
```
- Useful for finding max and min in an array etc. Results that expect a single output
