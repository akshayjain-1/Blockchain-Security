- String slicing is the process of creating a sub string from a portion of string
    - string.slice(start, end)

**The end index is not included**

- If end index is not specified, it defaults to the end of string
- You can reference the end of the string using -ve index = -1 for last char ...
```
const name = "abscdfg";

subname = name.slice(0,2);
