- If a condition is true, execute some code else do something else
```
let age = 18;

if(age >= 18){
    console.log("You are old enough!");
}
else{
    console.log("You cannot enter the site")
}

// Conditions also work with boolean
let isStudent = true;

if(isStudent){
    console.log("You are a student");
}
else{
    console.log("You are not a student");
}
```
- You can also nest if statements
```
let age = 25;
let hasLicense = false;

if(age>=16){
    console.log("You are old enough to have a license");
    if(hasLicense){
        console.log("You also have your license");
    }
    else{
        console.log("You dont have your license");
    }
}
else{
    console.log("You are not old enough to have your license");
}
```
- You can also define multiple conditions
```
if(<condition>){
    ...
}
else if(<condition>){
    ...
}
else{
    ...
}
```
- *** When defining multiple conditions using if..else if...else, the order of clauses matter!!!! Once any 1 of the condition matches, it will exit the if clause without checking rest of the conditions***
