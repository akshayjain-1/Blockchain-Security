- Destructuring: extract values from arrays and objects and assign them to variables
    - [] = arrays (list)
    - {} = objects (dictionary)


```
example - swap elements

let a = 1;
let b = 2;

[a,b] = [b,a]

console.log(a); // a = 2
console.log(b); // b = 1
```

```
const person1 = {
    name: "abcd",
    age: 30,
    job: "cook",
}

const {name, age, job="Unemployed"} = person1; // job was assigned a default value in case the value was not present in object

console.log(name);
console.log(age);
console.log(job);
```
