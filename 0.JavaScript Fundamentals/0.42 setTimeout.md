- setTimeout(): function allows you to schedule the execution of a function after a set amount of time (milliseconds)
    - setTimeout(callback, delay)

```
function sayHello(){
    window.alert("Hello");
}

setTimeout(sayHello, 3000) // 3 seconds

// you can directly define the function as well instead of callback in the parameter
```

- clearTimeout(timeoutId): Can cancel a timeout before it occurs
```
const id = setTimeout(() => windows.alert("Hello"), 3000);
clearTimeout(id); // nothing will happen because the timeout was cancelled so the function never executes
```
