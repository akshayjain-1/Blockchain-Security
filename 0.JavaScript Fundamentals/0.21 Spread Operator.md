- Spread Operator allows an iterable such as an array or string to be expanded into separate elements. It basically unpacks the elements
- represented by `...`
- Imagine that you are opening a box and taking all the stuff outside

```
let numbers = [1,2,3,4,5];

// if we were to find the max within the array and we tried
let max = Math.max(numbers); // it returns Nan

// but we can inpack the array into individual elements and then use them
let max = Math.max(...numbers);

// Similarly you can unpack string into chars
```

- After unpacking we can also join them back using the `join()` operator
```
let username = "abcd";
let letters = [...username].join("-") // returns a-b-c-d
```

- We can also combine multiple array using the spread operator
```
let fruits = ["apple", "mango", "banana"];
let veg = ["carrots", "celery"];
let basket = [...fruits, ...veg]; // displays the combined array
```
