- Synchronous: executes code line by line in sequential manner. Code waits for the operation to finish before executing the next line

- Asynchronous: Allows multiple operations to be performed concurrently without waiting. Doesnt block operation flow and allows operation to continue. Typically found in I/O operations, networking requests, data fetches etc. Handled with callbacks, promises and async/await

```
e.g: Synchronous code

console.log("1");
console.log("3");
console.log("2");

// task 2 will not print until 2 is printed and 3 will not print until 2 is printed. The order is sequential and waits fore previous operation to finish
```

```
e.g. Async code

setTimeout(() => console.log("1"), 3000) // log 1 after 3 seconds

console.log("2");
console.log("3");
console.log("4");

// in this case since we set a wait of 3 seconds for the setTimout function, 2,3,4 are already logged instead of waiting for setTimout to finish first

// outputs 2,3,4 ... (3 sec wait) 1

setTimout is a async function and hence runs concurrently instead of other waiting for it to fininsh

If we want 2,3,4 to be logged after 1, we can use callbacks, promises, async/await

function fucn1(callback){
    setTimeout(() => {console.log("1");
                      callback()}, 3000) // after line 1 is executed, call the callback function
}

function func2(){
    console.log("2");
    console.log("3");
    console.log("4");
}

func1(func2); // paranthesis not needed, if paranthesis are added, it executes the code immediately
```
