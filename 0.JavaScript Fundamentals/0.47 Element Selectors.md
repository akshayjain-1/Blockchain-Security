- Element Selectors: Methods used to target and manipulate HTML elements. THey allow you to select one or multiple HTML elements via DOM. Some examples are
    - document.getElementById() // returns a single element or null 
    - document.getElementsClassName() // returns a HTML Collection (array of elements and their properties belonging to the specified class name. individual element can be accessed via index value)
    - document.getElementbyTagName() // similar to getElementsClassName, but instead of class name accepts tag name
    - document.querySelector() // return first matching element or null (query can be class (accessed via `.classname`), tag, or `#id` )
    - document.querySelectorAll() // returns Nodelist -> similar to HTML collections but have their own inbuilt functions (such as forEach) and are static and do not automatically update in DOM

HTML collections are not Array collections, but they can be typcasted into one and then we can apply functions such as forEach() to them. To type case use the `Array.from(<collection name>)` method
