- NodeLists: Static collection of HTML elements by (id, tag, class).
    - Can be created using querySelectorAll()
    - Similar to an array but no filter, map, reduce functions. They do have a forEach method
    - NodeLists won't update to automatically to reflect changes
        - e.g: if you remove an element from DOM and it is within a nodelist, you would have to seperately remove the element from nodelist

```
Assume in HTML you have declared 4 buttons all belonging to the same class myButtons

buttons = document.querySelectorAll(".myButtons"); // creates a node list of all buttons

buttons.forEach(button => {
    button.addEventListener("click", event => {
        event.target.style.backgorundColor = "red";
    })
})

// Each button has an event listener which is listening for a click event and as you click the button, it changes the color to red
```
