- Error: An object is created to represent the errors that occur. Often occur with accepting user input or establishing a connection
    - The reason we use this is that, an error may result in premature exit of the program leading to unwanted program behavior. Simple things like misspells or incorrect references  can cause such errors
    - There we handle errors using the try, catch, finally block
        - try {} - actual code logic
        - catch {} - handle any errors
        - finally {} - Optional block, code here always executes

```

try{
    console.log(x);
    ...
}

catch(error){
    console.error(error);
}

// If wanted can include a finally block which is always executed irrespective of error or not

console.log("End");
```

- when you execute this - since x is not defined it results in a reference error and based on our code, it prints the error and then the final "End" statement, which means the program did not exit prematurely but was correctly handled.
- Great for debugging.

- You can also define custom error objects
```
if (x == 0){
    throw new Error("Cannot enter 0");
}
```
