- Objects: Collection of related properties and or methods
    - obj = {
        key:value/function() }
- Similar to python dictionaries

```
const person1 = {
    firstName: "ABCD",
    lastName: "DEFG",
    age: 20,
    isEmployed: true,
    sayHello: function(){console.log("Hello")}
}
```
- Can access individual element of the object via the `.` operator
    - `console.log(person1.firstName)`
    - `person1.sayHello();`
