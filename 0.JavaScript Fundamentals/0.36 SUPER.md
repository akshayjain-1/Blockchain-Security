- Super:  keyword used in classes to call the constructor or access properties and methods of a parent class
    - Parent is also known as super class
    - this = this object
    - super = parent 

```
class Animal {
    constructor(){

    }
}

// child extends parent

class Rabbit extends Animal(){
    constructor(name, age, runSpeed){
        this.name = name;
        this.age = age;
        this.runSpeed = runSpeed;
    }
}

class Fish extends Animal(){
    constructor(name, age, swimSpeed){
        this.name = name;
        this.age = age;
        this.swimSpeed = swimSpeed;
    }
}

const rabbit = new Rabbit("rabbit", 1, 25);
const fish = new Fish("fish", 2, 12);

// now if the code is executed - it returns an error (Uncaught reference error) - must call super constructor in derived class before accessing this keyword

which basically means, before using the this keyword in the child class constructors, we must call the constructor from the parent class

so the update child class would look like

class Rabbit extends Animal(){
    constructor(name, age, runSpeed){
        super(); // invokes the constructor of parent
        this.name = name;
        this.age = age;
        this.runSpeed = runSpeed;
    }
}
```

- you can also access parent class's methods
```
class Animal {
    constructor(name, age){
        this.name = name;
        this.age = age;
    }

    move(speed){
        console.log(`This ${this.name} can move at ${speed}`)
    }
}

// child extends parent

class Rabbit extends Animal(){
    constructor(name, age, runSpeed){
        super(name, age);
        this.runSpeed = runSpeed;
    }

    run(){
        super.move(this.runSpeed)
    }
}

class Fish extends Animal(){
    constructor(name, age, swimSpeed){
        super(name, age);
        this.swimSpeed = swimSpeed;
    }
}

const rabbit = new Rabbit("rabbit", 1, 25);
const fish = new Fish("fish", 2, 12);

rabbit.run();
```
