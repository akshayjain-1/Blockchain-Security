- Promises: An object that manages asynchronous functions. Wrap a promise object around asynchronous code
    - "I promise to return a value"
    - Pending -> Resolved or rejected // promise object will be pending and will either be resolved or rejected based on completion status
    - new Promise((resolve, reject) => {asynchronous code})

- From previous lessons if you recall -> if code is asynchronous it does not wait for previous code to finish but instead executes in parallel which can result in unexpected order of execution or result. 
    - As a result to handle this situation we learned about adding callback to the function
        - function1(callback)

```
function step1(callback) {
  setTimeout(() => {
    console.log("Step 1 done");
    callback();
  }, 500);
}

function step2(callback) {
  setTimeout(() => {
    console.log("Step 2 done");
    callback();
  }, 300);
}

function step3(callback) {
  setTimeout(() => {
    console.log("Step 3 done");
    callback();
  }, 6700);
}

// --- The Pyramid of Doom ---
step1(() => {
  step2(() => {
    step3(() => {
      console.log("All steps completed!");
    });
  });
});
```
- So if there are many functions like this it results into "Callback hell" which makes the code impossible to read
- To avoid this we have Promises and async/await functions

- In this lesson we will focus on Promise functions
```
We will understand promise with the following example:

// Do the following in order

// 1. Walk the dog
// 2. Clean the kitchen
// 3. Take out the thrash

--------- Using Callbacks ----------

function walkDog(callback){
    setTimeout(() => {
        console.log("Dog walked");
        callback();
    }, 1500)
}

function cleanKitchen(callback){
    setTimeout(() => {
        console.log("Kitchen cleaned");
        callback();
    }, 4500)
}

function throwThrash(callback){
    setTimeout(() => {
        console.log("Thrash thrown");
        callback();
    }, 1500)
}

walkDog(() => {
    cleanKitchen(() => {
        throwThrash(() => {
            console.log("all tasks done");
        })
    })
})

--------- Using Promises ----------

function walkDog(){

    return new Promise((resolve, reject) => {
        setTimeout(() => {
            const dogWalked = true;

            if(dogWalked){
                resolve("dog walked"); // if resolved this will be the output
            }
            else{
                reject("Dog not walked");
            }
        }, 1500)
    })
}

function cleanKitchen(){

    return new Promise((resolve, reject) => {
        setTimeout(() => {
            resolve("kitchen cleaned);
        }, 4500)
    })
}

function throwThrash(){

    return new Promise((resolve, reject) => {
        setTimeout(() => {
            resolve("Thrash thrown);
        }, 500)
    })
}

// we call these functions via method chaining

walkDog().then(value => {console.log(value); return cleanKitchen()})
        .then(value => {console.log(value); return throwThrash()})
        .then(value => {console.log(value); console.log("all chores finished")})
        .catch(error => console.error(error));



// here value within the then function is the value retuned by the function definition (in this case the log statement)
// the catch method is present to catch any rejects and the value returned by rejects is what is represented by 'error' in the function
```
- When the promise is rejected, the other promises following it are not evaluated
