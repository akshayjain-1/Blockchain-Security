- Logical operators are used to combine or manipulate boolean values
    - && = AND -- all conditions must be true = true
    - || = OR -- atleast one condition must be true = true
    - ! = NOT -- if !true = false
```
const temp = 20;

if(temp>0 && temp < 30){
    console.log("temp is good");
}
else{
    console.log("temp is bad");
}
```
