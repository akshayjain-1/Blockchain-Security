The arithmetic operators available in JS by default are:
- `+`: Add
- `-`: Subtract
- `*`: Multiply
- `\`: Divide (returns the quotient)
- `**`: Power of
- `%`: returns the remainder of a division

The above symbols are known as operators and the operands can either be variables, values etc

```
// assume the value of student remains 30 for all indivdual operations below

let students = 30;
students = students + 1; // will return 31
students = students - 1; // will return 29
students = students * 2; // will return 60
students = students / 2; // will return 15
students = students ** 2; // will return 900
students = students % 2; // will return 0
```

Writing variables multiple times in the equation can be annoying and hence to avoid that we can use `augmented assignment operators`
```
student += 1; //same as student = student + 1

The same can be done for all operators
```

There are some ready operators such as increment and decrement operatory which can allow us to increase or decrease value by **only** 1
```
student ++; // increase by 1
student --; // decrease by 1
```

## Operator Precendence
- Given a very complex equation with multiple operators, operator precedence determines in which order to solve the equation (bodmas rule)
- The operator precedence is as:
    - parenthesis ()
    - exponents
    - multiplication, division and modulo
    - addition, subtraction
```
let result = 1 + 2 * 3 + 4 ** 2;

So the working for the above equation would be:
4 ** 2 = 16 (exponent are next in priority after parenthesis)

equation = 1 + 2 * 3 + 16

2 * 3 = 6 (as multiplication takes higher precedence than addition)

equation = 1 + 6 + 16

result = 23

console.log(result) // should return the same 23 by the logic explained above
```
