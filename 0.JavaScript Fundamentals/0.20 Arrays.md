Array - It is a variable like structure that can hold more than 1 value
- We can do so by enclosing all the values within [] adn listing the values as comma separated
- To access a specific element of the array, you can do it by using the index number


```
let fruits = ["apple", "mango", "cherry"];
console.log(fruits[0]) // logs apple


fruits.push("coconut"); // push an element to the end
fruits.pop(); // remove the last element

fruits.unshift("mango") // add an element to the beginning to the array
fruits.shift(); // remove an element from the beginning

fruits.length; // length of array

fruits.indexOf("apple"); // index of element, for an element that does not exist, it returns -1

fruits.sort(); // sort the elements in alphabetical order 
fruits.sort().reverse() // sort in reverse order
```
