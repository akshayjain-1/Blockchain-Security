- Repeat some code WHILE the condition is still true
- if the condition is always true, it will run the loop 
- In the while loop, it checks the condition first and then executes the code
```
let age = 1;

while(age<18){
    console.log(`${age}`);
    age += 1;
}
// will run the code until age is 18
```

- Another variation of this is the do while loop, where it first executes the code and then checks for the condition. So even if the condition is false, the code will be executed once
```
do{
    ...
}while(<condition>)
```
