- Variables that cant be changed
```
let pi = 3.14; // pi is declared as a normal variable and if at any point it is changed, the calculation changes
let r;
let c;

r = window.prompt("Enter the radius of the circle");
r = Number(r);
c = 2 * pi * r;

// to define a variable as const, replace the 'let' with 'const'
const PI = 3.14; // generally constant variables storing number and datatypes are declared in all caps. strings are not, but that is simply about preferences
```
