- Variables: a container that stores some value. These values can be of different types
- To declare a variable: use the keyword `let` {variable name} 
    ``` 
    let x; 
    x = 100;
    console.log(x); // would display the value of x in console

    // Can combine the declaration and assignment together
    let x = 100;
    ```

- **You can use the `typeof` keyword to check the data type of a variable**

## Data Types
1. Numbers:
    - This consists of integers, float values etc
    ```
    let age = 25;
    let price = 2.55;
    let gpa = 3.5;

    console.log(`you are of the age ${age});
    console.log(typeof age);
    ```

2. Strings:
    - Collection of characters. Can create using strings using either ".." or '..'
    - `let firstName = "Bob"`

3. Booleans:
    - True or False values. Typically used as flags in the programs
    - `let online = true;`
    - `let offline = false;`
