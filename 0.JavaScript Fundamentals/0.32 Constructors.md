- Constructors: These are special methods that used for defining properties and methods of an object
- This comes in handy when we are not creating objects manually

```
function Car(make, model color, year){
    this.make = make,
    this.model = model,
    this.color = color,
    this.year = year
}

const car1 = new Car("Ford", "Mustang", "red", 2024); // `new` keyword before the Car function call

console.log(car1.make);

// The Car method is reusable and can be used to create as many objects as we want as it is only defining the skeleton of the object

// The constructor can also have other code apart from variable assigment
```
