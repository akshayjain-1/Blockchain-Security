- Async/Await:
    - Async: makes a function return a promise
    - Await: Makes an async function wait for a promise
- Allows you to write async code in a synchronous manner. Async doesnt have a reject, resolve paramater. Everything after await is placed in an event queue

```
Building on the code from the previous lesson of Promises, 
since Async function does not have a resolve/reject parameter, we define the functions separately which return promises and then club them with await

function walkDog(){
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            const dogWalked = true;

            if(dogWalked){
                resolve("dog walked"); // if resolved this will be the output
            }
            else{
                reject("Dog not walked");
            }
        }, 1500)
    })
}

function cleanKitchen(){
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            resolve("kitchen cleaned);
        }, 4500)
    })
}

function throwThrash(){
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            resolve("Thrash thrown);
        }, 500)
    })
}

async function doChores(){
    try{
        const walkDogResult = await walkDog(); // await makes the async function wait for the inner function to return a promise
        console.log(walkDogResult)

        const cleanKitchenResults = await cleanKitchen();
        console.log(cleanKitche);

        const throwThrashResults = await throwThrash();
        console.log(throwThrashResults);
    }
    catch(error){
        console.error(error);
    }
    
}

doChores();
```

- this allows us to write async function similar to a synchronous code making it much easier to read and manage
- await is only valid within an async function
