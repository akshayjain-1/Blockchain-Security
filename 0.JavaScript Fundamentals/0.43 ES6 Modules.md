- ES6 module: It is an external file that contains reusable code that can be imported into other JS files and programs. It consists of variables, classes and functions and more.
    - When referencing in the HTML file in the `<script>` tag, use the type=module parameter as well
        - `<script type="module" src="index.js"></script>`

```
Assume we created a mathUtil.js file containin reusable math functions based code. To make the functions, class, variables importable, need to prefix them with `export` keyword

// mathUtil.js

export const PI = 3.14

export function area(radius){
    return PI * radius * radius;
}

then in index.js

import {PI, area} from `./mathUtil.js`; // we then use these variables and functions as if they were part of index.ks itself

console.log(PI);

const area = area(4);
console.log(`${area}`)
```
