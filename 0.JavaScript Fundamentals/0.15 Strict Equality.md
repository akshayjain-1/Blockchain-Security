Different equality operators
    - '=': Assignment operator
    - '==': comparison operator (if 2 values are equal)
    - '===': strict comparison (if the values and the datatype are same)
    - '!=': inequality operator -- will return true if 2 values are not equal, disregards the data type
    - '!==': strict inequality operator -- will return true if 2 values and datatypes are not equal 

```
const PI = 3.14;

// if you do PI == "3.14" -- this will return true because it only compares the value and not the data type
// if you do PI === "3.14" -- this will return false becuase the datatypes are different
