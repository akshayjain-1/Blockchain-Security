- EventListeners: Listen for specific events to trigger any action when that event occurs
    - Some of the common events are: click, mouse over, mouse out
    - the function to trigger code on the event is:
        - addEventListener(event, callback); // the event object is provided by the web browser automatically when something happens containing details about what happened exactly

```
const myBox = document.getElementById("myBox");
const myButton = document.getElementById("myButton");

function changeColor(event){
    event.target.style.backgroundColor = "tomato";
    event.target.textContent = "Ouch!";
}

myButton.addEventListener("click", changecolor);

// Instead of passing a callback, you can also pass an arrow function or directly define the function in the parameter
```
