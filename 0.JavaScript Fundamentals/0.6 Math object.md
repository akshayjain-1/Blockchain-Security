- Math is a built in object that provides a collection of properties and methods
    - e.g: We can directly get the values of constants like Pi, or E (euler's number) using Math.PI or Math.E

```
let x = 3.21;
let y = 2;
let z;

z = Math.round(x); // will round to closest integer value, in this case 3
z = Math.floor(4.99); // floor will always round down so in this case 4
z = Math.ceil(2.11); // always rounds up, in this case it will be 3

z = Math.trunc(x); // It will eliminate any decimal portion - so 3

z = Math.pow(2,5); // 2 ^ 5

z = Math.sqrt(81); // square root

z = Math.log(3); // Natural logarithm of a number

z = Math.sin(45); // It is 45 radiants
z = Math.cos(45); // It is 45 radiants
z = Math.tan(45); // It is 45 radiants

z = Math.abs(-4.32); //removes the negative sign

z = Math.max(1.3.5); // stores the max value - 5
z = Math.min(3.5.1); // stores the min value - 1

z = Math.random(); // Generates a random number between 0 and 1 in decimals
```
