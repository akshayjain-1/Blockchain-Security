- classList: Element property in JS used to interact with an element's list of classes (CSS classes)
    - Allows you to make reusable CSS classes for many elements 
    - You can define properties for a CSS class and the just add new elements to that class and they will automatically inherit all the CSS properties for that class
    - Available functions for classList are:
        - add()
        - remove()
        - toggle() // remove if present, add if not
        - replace(oldClass, newClass)
        - contains()
