- Arrow Functions: Simple and concise way to write function **expression**. Good for functions that you use only once 
    - `(parameters) => some code`
    - If you want to include more than 1 statement you need to enclode the code in {}
        - `(params) => {<multiple line of code>}`
    - `return` keyword is optional if there is only 1 line of code
```
Normally we would define a function and then call it

function hello(){
    console.log("hello");
}
hello();

// Lets first convert it to an function expression. Lets say we chose function expression as variable

const hello = function(){
    console.log("Hello");
}

hello();

// This can further be concised into an arrow function following the syntax (parameter) => some code. Here we dont have any params
const hello = () => console.log("Hello");
hello();

Example 2

function hello(){
    console.log("Hello");
}

setTimeout(hello, 3000); // this is a callback function

// Lets convert this into function expression as value

setTimeout(function(){
    console.log("Hello");
}, 3000)

// We can further shorten it using arrow function

setTimeout( () => console.log("Hello"), 3000);

// Example 3 - Applying arrow function to map()


const numbers = [1,2,4]

function square(element){
    return Math.pow(element,2)
}

numbers.map(square)

// Using Arrow function
const squares = numbers.map( (element) => Math.pow(element,2));
```
