Inheritence: Allow a class to inherit properties and methods from another class (parent -> child). Helps with code reusability

```
class Animal {
    alive = true;

    eat(){
        console.log(`This ${this.name} is eating`);
    }
}

// child extends parent

class Rabbit extends Animal(){
    name = "Rabbit";
}

class Fish extends Animal(){
    name = "Fish";
}

const rabbit = new Rabbit();
const fish = new Fish();

rabbit.eat(); // It should display the log statement with this.name referencing rabbit
```

- Helps with code reusability, as the code in parent class can be reused by all children classes avoiding declaration of the same code for each child and then each child can have code specific to themselves as well
