- Function declaration: Define a reusable block of code that performs a task
- Function Expression: A way to define function as values or expression
    - In function expression we can assign function to a variable or pass it as a value to another function
```
// Function Declaration
function hello(){
    console.log("hello);
}

// Function expression as variable
const hello = function(){
    console.log("Hello");
}

hello();

// Function expression as value: similar to what we saw in callback function, but instead of passing the function name, we pass the entire function definition

setTimeout(callback, 3000) // this is what we saw in callback

instead

setTimeout(function(){
    console.log("Hello");
}, 3000);
```
