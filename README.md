# Blockchain Security

A structured learning and practice repository for understanding, testing, and defending blockchain systems and decentralized applications.

This repository tracks the progression from blockchain fundamentals to hands-on security research. Notes, labs, scripts, write-ups, and vulnerability reports should be added here as evidence of practical learning. The goal is to turn each completed topic into a demonstrable skill that can later be summarized on a resume or discussed in technical interviews.

## Goals

- Understand how blockchains, smart contracts, wallets, and decentralized applications work.
- Learn how to identify, reproduce, and explain common blockchain security vulnerabilities.
- Build practical experience with smart contract testing, auditing, threat modeling, and secure development.
- Maintain clear evidence of completed labs, projects, tools, and security findings.
- Convert completed work into concise, evidence-based resume bullets.
